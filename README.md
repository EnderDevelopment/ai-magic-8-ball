# AI Magic 8 Ball

The AI Magic 8 Ball is a Minecraft plugin that adds a smart magic ball to your server. This plugin allows players to ask questions to the magic ball, which responds with answers in the chat. The plugin is designed to be simple and easy to use, making it perfect for adding a fun and interactive element to your Minecraft server.

## Install

1. Download the plugin JAR file from the releases section of this repository.
2. Place the JAR file in the `plugins` folder of your Minecraft server.
3. Restart or reload your server to load the plugin.

## Use

1. Players can interact with the magic ball by using the `/magicball` command followed by their question.
2. The magic ball will respond with an answer in the chat.
